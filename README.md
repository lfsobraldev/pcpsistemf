# Sobral PCP Industrial V2

Refatoração completa da interface para padrão PCP/ERP industrial.

Inclui:
- Login corporativo.
- Menu lateral.
- Dashboard operacional.
- KPIs e gráficos recalculados em tempo real.
- Nova programação.
- Leitura de Pedido PDF.
- Diagnóstico da leitura.
- Revisão tabular.
- Quantidades consolidadas para líderes.
- Apontamentos.
- Exportação Excel por grupo.
- Histórico e configurações preparados para persistência.

Vercel:
ADMIN_USER
ADMIN_INITIAL_PASSWORD
AUTH_SECRET

Rodar:
npm install
npm run dev
